# 如何把模块加到页面上

按下面步骤在**主题编辑器**里操作即可，无需懂代码。

1. 登录店铺后台，打开 **主题** → **编辑**（或「自定义」首页等页面）。
2. 在左侧或中间页面预览区，找到要插入的位置（例如某两个区块之间）。
3. 点击 **添加分区**（或「添加区块」「Add section」）。
4. 在列表里往下找，选中你要的模块名称（各组件后台显示名见 [组件总览](/components/)）。
5. 点右侧出现的设置项，填标题、图片、链接等。
6. 需要多张卡片时，点分区里的 **添加块** / **添加卡片**，每添加一次就多一张。
7. 改完后点右上角 **保存**。

> 若列表里找不到对应名字，说明当前主题还没装上该模块，需要先让技术同事把主题更新好。

# 如何在手册里「登记」新组件

每当在 **Shopline** 主题里开发了一个新的自定义分区，请在本手册仓库按下面做，保证运营只看这一份说明。

## 1. 更新组件总览表

编辑 [组件总览](/components/) 对应的源文件：`components/index.md`。

在表格里增加一行：

| 列 | 写什么 |
|----|--------|
| 组件 | 主题编辑器里出现的分区名称 |
| 介绍 | 一句话说明用途 |
| 使用 | 链到详细说明页 |

## 2. 新增一篇组件说明

1. 复制 `components/` 下任意一篇现有说明。
2. 改名并改写：适合做什么、分区设置表、子块表、小提示。
3. **不要**写具体店铺名、主题仓库名，**不要**贴含真实商品/店铺数据的截图。
4. 总览表里的链接指向新路径。

## 3. 左侧导航

编辑 `.vitepress/config.mts` → `sidebar` →「Shopline 组件」分组，增加一条链接。

## 4. 预览与发布

```bash
npm run dev
git add .
git commit -m "docs: register new component"
git push
```

等待 GitHub Actions 部署完成后，线上地址即更新。

# 截图占位目录

每个组件文档顶部都引用了 `/screenshots/<slug>.png`。

放图就把 PNG 命名为 `<slug>.png` 丢进这个目录，commit + push，1~2 分钟后线上自动生效。

## 命名对照

| 组件 slug | 截图文件 |
|---|---|
| kol-recommend | kol-recommend.png |
| text-columns-renman | text-columns-renman.png |
| text-columns-renman2 | text-columns-renman2.png |
| product-ranking | product-ranking.png |
| tab-switcher | tab-switcher.png |
| image-swiper-more | image-swiper-more.png |

## 推荐规格

- **宽度**：1200~1600 px（电脑端后台编辑器全屏截图，截到关键设置项）
- **格式**：PNG 优先（透明 / 边框清晰），太大可用 [TinyPNG](https://tinypng.com/) 压缩
- **打码**：截图里如果有 SKU / 客户名 / 价格之类的敏感信息，先打码再传

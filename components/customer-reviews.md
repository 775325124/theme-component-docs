# 客户评价（みんなの口コミ）

::: info 适用范围
**Shopify（Liquid）** · 主题：pettena-jp
:::

**适合做什么：** 在首页或专题页横滑展示多条「买家好评」卡片：大图、商品标签、评论标题、星级、短评正文、日期，整张卡片可点进商品页。适合日文站「みんなの口コミ」类口碑模块。

> 配合用法：每条评论建议先 **关联商品**，图片 / 商品名 / 链接会自动带出；只需再写评论文案。也可完全手填，不绑商品。

![客户评价前台效果](/screenshots/customer-reviews.png)

## 整段（分区）设置

### 标题

| 名称 | 怎么填 |
|------|--------|
| 主标题（英文） | 大标题，例如 `Customer Reviews`；留空则不显示 |
| 副标题（日文） | 小字说明，例如 `みんなの口コミ`；留空则不显示 |

### 移动端分页

| 名称 | 怎么填 |
|------|--------|
| 移动端指示器 | **小圆点** / **进度条** / **不显示**（默认小圆点）。仅手机端显示；电脑端用左右箭头 |

### 颜色

| 名称 | 怎么填 |
|------|--------|
| 正文文字颜色 | 标题、商品名、评论正文等，默认 `#473522` |
| 日期文字颜色 | 日期行，默认 `#7D7778` |
| 链接文字颜色 | 底部「查看商品」类链接，默认 `#FF7F40` |
| 星星颜色 | 评分星级，默认 `#FFB400` |
| 评论小标签背景色 | 「購入者レビュー」等胶囊标签底色，默认 `#FBE7DC` |
| 评论小标签文字颜色 | 胶囊标签字色，默认 `#FF7F40` |

### 布局

| 名称 | 怎么填 |
|------|--------|
| 内容最大宽度（px） | 整块内容区最大宽度，800～1600，默认 1200 |
| 上间距 / 下间距（px） | 分区上下留白，0～200，步长 4，默认各 60 |

## 前台展示规则（运营须知）

| 端 | 表现 |
|----|------|
| **电脑** | 一行约 **3 张** 卡片；左右有圆形箭头，每次滑 **1 张** |
| **手机** | 横滑，一屏约 **1.25 张**（露出下一张边缘）；箭头隐藏，用圆点或进度条 |

评论正文在页面上**最多显示 2 行**，超出部分省略，保证卡片高度整齐。

## 每一张「评论」块里填什么

最多 **10** 条评论块。

### 关联商品（推荐）

| 名称 | 怎么填 |
|------|--------|
| 关联商品 | 选一个 Shopify 商品。下面未单独填写的 **图片 / 商品名 / 跳转链接** 会自动用该商品的主图、标题、商品页 URL |

### 图片与链接（可覆盖商品）

| 名称 | 怎么填 |
|------|--------|
| 图片（覆盖商品图） | 上传买家图或场景图；不填则用关联商品主图 |
| 图片比例 | 4:5（默认）/ 1:1 / 3:4 / 16:9 |
| 跳转链接（覆盖商品链接） | 整张卡片点击去向；不填则用商品页链接。无链接时卡片不可点，底部链接文字也不显示 |

### 文案与评分

| 名称 | 怎么填 |
|------|--------|
| 商品标签文字 | 图下方小灰字，例如 `2 頭｜10.1kg 〜 15kg` |
| 商品名（覆盖商品标题） | 粗体商品名；不填则用商品标题 |
| 评论标题 | 短标题，例如 `コンパクトなのがいい` |
| 显示评分星星 | 开/关，默认开 |
| 评分（0-5） | 整数 0～5，默认 5 |
| 评论小标签文字 | 星星旁胶囊，例如 `購入者レビュー` |
| 评论正文 | 多行文字；前台只显示 2 行 |
| 日期 | 例如 `2026.01.27` |
| 链接文字 | 有跳转链接时显示，例如 `この商品を見る >` |

### 填写优先级（避免搞混）

```text
图片     → 块里上传的图片 ＞ 关联商品主图
商品名   → 块里填的名称   ＞ 商品标题
链接     → 块里填的 URL   ＞ 商品页 URL
```

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------------|
| 整块不显示 | 没有添加任何「评论」块，或分区被关闭 |
| 没有左右箭头 | 评论不足 3 条时可能滑不动，属正常；手机端本来就不显示箭头 |
| 点了卡片没反应 | 未填跳转链接且未关联商品，或链接文字留空（有链接才显示底部文案） |
| 星星数量不对 | 检查「评分」滑条是否为 0～5 的整数 |
| 正文显示不全 | 设计为最多 2 行；需要更长内容请缩短文案或改商品详情页 |
| 颜色和品牌不一致 | 在分区「颜色」里改链接色、星星色、标签色即可 |

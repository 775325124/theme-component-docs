# 人员穿搭展示

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：sosove-jp
:::

**适合做什么：** 展示员工 / KOL 的穿搭搭配卡片，支持网格平铺和横滑轮播两种布局。每张卡片可放一张穿搭大图、头像和名字标签，并可跳转到指定页面。

本组件有**两种用法**：

| 版本 | 位置 | 数据来源 |
|------|------|----------|
| **通用分区版** | 可添加到任意页面 | 后台手动添加穿搭卡片 |
| **元字段版（商品详情）** | 商品详情页 block | 从商品元字段自动读取数据 |

> 配合用法：建议提前准备好统一宽高比的穿搭照片（推荐 3:4），视觉效果更整齐。

## 整段（分区）设置

### 标题

| 名称 | 怎么填 |
|------|--------|
| 标题 | 分区顶部大标题文字，默认「人员协调」 |

### 布局

| 名称 | 怎么填 |
|------|--------|
| 布局模式 | 网格 / 轮播 |
| 网格 · PC 每行列数 | 1～6，默认 3（仅网格模式生效） |
| 网格 · 移动端每行列数 | 1～3，默认 2（仅网格模式生效） |
| 轮播 · PC 每屏可见数 | 10～100，默认 26；实际数量 = 数值 ÷ 10，例如 26 = 2.6 张（可露出下一张边缘）。仅轮播模式生效 |
| 轮播 · 移动端每屏可见数 | 10～100，默认 20；同上除以 10。仅轮播模式生效 |

### 轮播 · 交互（仅轮播模式）

| 名称 | 怎么填 |
|------|--------|
| 显示左右箭头 | **开**：卡片两侧显示前/后切换箭头（多于 1 张时可见）；**关**：隐藏箭头 |
| 自动播放 | **开**：自动轮播（系统开启「减少动态效果」时不会自动播放）；**关**：手动滑动 |
| 自动播放间隔 | 3000～10000 ms，每次 500 ms，默认 4000 ms |

### 图片比例（固定）

| 名称 | 怎么填 |
|------|--------|
| PC 端主图比例 | 1:1 / 3:4 / 4:3 / 16:9，默认 3:4 |
| 移动端主图比例 | 1:1 / 3:4 / 4:3 / 16:9，默认 3:4 |

### 底部操作

| 名称 | 怎么填 |
|------|--------|
| 查看更多按钮文案 | 按钮上显示的文字，需与链接同时填写才会显示 |
| 查看更多按钮链接 | 顾客点击按钮跳到哪里，例如合集页 / 自定义页面 |

### 分区填充

| 名称 | 怎么填 |
|------|--------|
| 分区填充 | 主题自带的内部留白控件 |

## 每一个「穿搭卡片」里填什么

最多可添加 24 张穿搭卡片。

| 名称 | 怎么填 |
|------|--------|
| 主图 | 上传一张穿搭照片，建议保持与上方「图片比例」一致 |
| 头像（可选） | 上传人员头像小图，显示在卡片底部 |
| 标签文案 | 品牌名 / 人员姓名，默认「品牌 / 姓名」 |
| 卡片链接（可选） | 顾客点击整张卡片跳到哪里，不填则不可点击 |

## 元字段版（商品详情页）

::: tip 什么时候用元字段版？
当你希望**不同商品自动展示不同的穿搭卡片**时，使用元字段版。数据绑定在商品上，无需逐个在后台添加卡片块。
:::

### 前置准备：创建商品元字段

在 Shopline 后台 **设置 → 元字段 → 商品** 中新建一个 JSON 类型的元字段：

| 项目 | 填什么 |
|------|--------|
| 命名空间 | `my_fields` |
| 键名 | `staff_coordination` |
| 类型 | JSON |

### 元字段数据格式

在需要展示穿搭的商品上，填入以下格式的 JSON（可参考下方测试用例）：

| 字段 | 必填 | 说明 |
|------|------|------|
| title | 否 | 区块标题，例如「人员协调」；不填则不显示标题 |
| cta.label | 否 | 「查看更多」按钮文案 |
| cta.url | 否 | 「查看更多」按钮链接 |
| items | 是 | 穿搭卡片数组，每项见下表 |

每一条 item：

| 字段 | 必填 | 说明 |
|------|------|------|
| main_image | 是 | 穿搭大图 URL（字符串）或含 src/alt 的对象 |
| avatar | 否 | 头像图 URL 或含 src/alt 的对象 |
| label | 否 | 人员名 / 品牌名 |
| card_url | 否 | 点击卡片跳转的链接，留空则不可点击 |

### 元字段版后台设置

在商品详情页模板中添加「人员穿搭（元字段）」block 后，可配置以下选项（布局和轮播控制与通用分区版相同）：

#### 布局与列数

| 名称 | 怎么填 |
|------|--------|
| 布局模式 | 网格 / 轮播（默认轮播） |
| 网格 · PC 每行列数 | 1～6，默认 3（仅网格模式生效） |
| 网格 · 移动端每行列数 | 1～3，默认 2（仅网格模式生效） |
| 轮播 · PC 每屏可见数 | 10～100，默认 26；实际 = 数值 ÷ 10。仅轮播模式生效 |
| 轮播 · 移动端每屏可见数 | 10～100，默认 20；同上除以 10。仅轮播模式生效 |

#### 轮播 · 交互

| 名称 | 怎么填 |
|------|--------|
| 显示左右箭头 | **开**：显示前/后箭头；**关**：隐藏 |
| 自动播放 | **开**：自动轮播；**关**：手动滑动 |
| 自动播放间隔 | 3000～10000 ms，默认 4000 ms |

#### 图片比例

| 名称 | 怎么填 |
|------|--------|
| PC 端主图比例 | 1:1 / 3:4 / 4:3 / 16:9，默认 3:4 |
| 移动端主图比例 | 1:1 / 3:4 / 4:3 / 16:9，默认 3:4 |

> 元字段版没有「标题」「查看更多按钮」「分区填充」等设置项——这些信息直接写在商品的 JSON 元字段里。

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------------|
| 轮播模式下只有一张也显示箭头 | 只有一张卡片时箭头自动隐藏；如果仍显示请检查是否有多个空卡片 |
| 图片上下被裁切 | 检查「图片比例」设置和原图宽高比是否匹配 |
| 「查看更多」按钮不出现 | 文案和链接必须同时填写，缺一不显示 |
| 轮播不自动播 | 确认「自动播放」已开启且卡片多于 1 张；若系统开启了「减少动态效果」也会停止自动播放 |
| 元字段版：商品详情页没显示穿搭区块 | 确认商品的元字段 `my_fields.staff_coordination` 已填写且 JSON 格式正确、items 数组不为空 |
| 元字段版：图片不显示 | main_image 可以是纯 URL 字符串，也可以是含 src 字段的对象，检查格式是否符合上方说明 |

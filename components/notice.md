# 通知消息

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：kenpogen
:::

**适合做什么：** 公告 / お知らせ列表页：顶部标题 + 副标题，下面按日期列出已发布的**自定义页面**链接（适合店铺通知、活动说明归档）。

![通知消息前台效果](/screenshots/notice.png)

## 整段（分区）设置

### 标题区

| 名称 | 怎么填 |
|------|--------|
| 标题 | 页面主标题，例如「お知らせ一覧」 |
| 标题大小 | 大-标题1 / 中-标题3 / 小-标题5，默认中-标题3 |
| 标题粗细 | 正常 / 加粗 |
| 副标题 | 标题下方居中一行说明（前后会自动加「-」装饰） |
| 副标题大小 | 默认 / 标题1～6 / 正文1～6，默认正文3 |
| 分区填充 | 分区上下留白 |

## 每个「通知条目」块

| 名称 | 怎么填 |
|------|--------|
| 自定义页面 | 选择已在后台创建并发布的页面；前台显示该页标题、发布日期，点击跳转 |

> 每条只关联一个页面。日期取页面**发布时间**；未选页面或页面未发布时该条不显示。

## 常见用法

1. 在 **在线商店 → 页面** 里为每条通知单独建页面（正文写详细内容）。
2. 新建 **通知消息** 分区，标题填列表页名称。
3. 逐个添加 **通知条目** 块，每条绑定对应页面。
4. 将含该分区的模板用于「通知列表」专用页面，并在导航里链过去。

## 小提示

- 列表顺序与后台块顺序一致，最新的条目通常放在最上面（需手动调整块顺序）。
- 条目左侧固定显示「お知らせ」标签文案（主题写死，暂不能在后台改）。

# 热门标签（Hot tags）

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：kenpogen
:::

**适合做什么：** 在首页或专题页展示一排可点击的标签按钮，引导顾客进入集合页、搜索页或自定义链接。可配分区标题与标签颜色、字号。

![热门标签前台效果](/screenshots/hot-tags.png)

## 整段（分区）设置

### 标题

| 名称 | 怎么填 |
|------|--------|
| 标题 | 分区上方大标题（可不填） |
| 标题大小 | 大-标题1 / 中-标题3 / 小-标题5，默认中-标题3 |
| 标题粗细 | 正常 / 加粗 |

### 标签样式

| 名称 | 怎么填 |
|------|--------|
| 配色方案 | 整块背景与文字配色（主题色板） |
| 标签背景色 / 标签悬停背景色 | 标签默认与鼠标移上去时的底色 |
| 标签文字颜色 / 标签悬停文字颜色 | 标签默认与悬停时的字色 |
| PC端文字大小 / 移动端文字大小 | 标签文字 px 滑条（默认 PC 15、手机 13） |
| 布局 | 标签区域 flex 布局（方向、对齐、行/列间距）；手机端建议换行 wrap |
| 边距 | 分区上下左右留白 |

## 标签组（块）

分区里先添加 **标签组** 块（一般只需一个），再在组内添加多个 **标签** 子块。

### 标签组设置

| 名称 | 怎么填 |
|------|--------|
| 配色方案 | 组内标签区域配色 |
| 布局 | **列间距 = 左右**，**行间距 = 上下**；标签多行时建议开启换行 wrap |
| PC / 移动端文字大小 | 覆盖分区级标签字号（10～32 px / 10～28 px） |
| 边距 | 标签列表区域内边距 |

### 每个标签子块

| 名称 | 怎么填 |
|------|--------|
| Tag | 标签上显示的文字 |
| Link | 点击后跳转的链接（集合、页面、外链等） |

## 小提示

- 标签组块 limit 为 1，所有标签都放在同一个组里即可。
- 悬停颜色与默认颜色对比要够明显，方便顾客识别可点击。
- 手机端标签较多时，调小「移动端文字大小」并适当减小行/列间距。

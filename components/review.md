# 评论（Review）

> 评论展示 section：星级评论卡片横向轮播，支持可选关联商品并在卡片图片上叠加加购弹窗，含桌面/移动端两套布局与底部「更多」按钮。

- 适用主题：kenpogen
- 平台：shopline-3.x
- 共用主题：[oakln]
- 登记日期：2026-07-29

## 功能说明

- **卡片轮播**：评论以卡片形式横向排列，桌面端每行 2–5 列可配，超出宽度可横向滚动，底部自动生成分页圆点（`review.js` 中的 `<review-carousel>` 自定义元素，图片加载后重算位点）。
- **星级展示**：每张卡片 1–5 星，用满星叠加裁剪实现任意百分比填充，星色可配。
- **移动端布局**：≤768px 自动切换为「两张卡片竖叠为一屏、卡片内左图右文」的横向卡片布局，评论内容支持桌面/移动端分别配置。
- **关联商品加购（可选）**：卡片关联商品后，图片优先取商品首图，并在图片四角之一显示加购图标，点击弹出加购弹窗（依赖共享组件 `components/quick-add-modal`）；可选开启「点击图片跳转商品详情页」。
- **底部更多按钮**：可配文字与链接，二者都为空时不展示。

## 组件依赖

- 共享组件：`components/quick-add-modal`（加购弹窗；移植到新主题时需一并携带）
- 图标组件：`icons/star`、`icons/quick-add`、`icons/loading-spinner`、`icons/close`
- 公共 block：`heading`、`subheading`
- 配色/排版：主题配色变量（`--color-button-*`、`--color-foreground`）、基础排版 class（`body2/4/5`、`title3`）

> 移植到其它 Sline(shopline-3.x) 主题时，确认上述依赖存在；oakln 已随本次一并补齐 `quick-add-modal`。

## 使用步骤

1. 在页面编辑器插入 section「评论(Review)」（预设分类：商品）。
2. 通过 `heading` / `subheading` block 配置标题与副标题。
3. 添加若干「评论卡片」block（上限 30），逐张设置：星级、标题、内容（桌面/移动端）、作者。
4. 需要加购时：卡片内选择「关联商品」，图片将优先用商品首图并显示加购图标；可开关「点击图片跳转商品详情页」。
5. section 级设置：桌面端列数、组件背景色、星级颜色、标题颜色、加购图标位置、底部按钮文字/链接、分区间距。

## Section 设置项

| 设置 | 类型 | 说明 |
| --- | --- | --- |
| 配色方案 | color_scheme | 默认 scheme-1 |
| 桌面端每行数量 | range 2–5 | 默认 4 |
| 组件背景色 | color | 默认透明 |
| 星级颜色 | color | 默认 #F5A623 |
| 评论标题颜色 | color | 默认 #E7749B |
| 加购图标位置 | select | 图片四角，默认右下角 |
| 底部按钮文字 / 链接 | text / url | 都为空时不展示按钮 |
| 分区填充 | style.spacing | 桌面 60/60、移动 32/32 |

## 评论卡片（block）设置项

| 设置 | 类型 | 说明 |
| --- | --- | --- |
| 评论图片 | image | 未关联商品时使用；关联后优先用商品首图 |
| 星级 | range 1–5 | 默认 5 |
| 评论标题 | text | |
| 评论内容（桌面端） | richtext | |
| 评论内容（移动端） | richtext | 留空则用桌面端内容 |
| 作者 | text | |
| 关联商品 | product | 选择后启用加购与商品首图 |
| 点击图片跳转商品详情页 | switch | 需先关联商品，默认开 |

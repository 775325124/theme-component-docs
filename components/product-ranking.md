# 产品排行榜（Tab 切换 + 排名徽章）

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：kenpogen
:::

**适合做什么：** 把多个「分类合集」做成顶部 Tab，点哪个 Tab 显示哪一类的商品；每张商品卡左上角带 1、2、3…的排名徽章，前三名颜色加重；底部可放「查看更多」按钮跳到对应合集页。

![后台截图占位](/screenshots/product-ranking.png)

> 配合用法：先在后台建好 X 个**商品合集（Collection）**（例如「パンプス」「ローファー」「ブーツ」），合集里的商品顺序就是排行顺序（你把想排第一名的拖到最前）。这个模块只负责把合集**按 Tab 形式**展示出来。

## 整段（分区）设置

### 大标题 / 副标题
| 名称 | 怎么填 |
|------|--------|
| 大标题 | 整段最上方的大字，例如「商品ランキング」 |
| 大标题字体大小 | 16～48 px 拖滑条 |
| 大标题字体粗细 | 正常 / 中等 / 半粗 / 粗体 / 特粗 |
| 副标题 | 大标题下面一行小字（可不填） |
| 副标题字体大小 / 字体粗细 | 同上 |

### 间距
| 名称 | 怎么填 |
|------|--------|
| 上间距 / 下间距 | 这一段与上下内容的距离（0～100 px） |
| 分区填充 | 主题自带的内部留白控件 |

### Tab 样式
| 名称 | 怎么填 |
|------|--------|
| Tab 选中字体颜色 | 当前选中的 Tab 文字色 |
| Tab 选中背景色 | 当前选中的 Tab 底色 |

> 未选中的 Tab 用主题默认色；只暴露了「选中态」给运营调色。

### 功能开关
| 名称 | 默认 | 说明 |
|------|------|------|
| 显示排行徽章 | 开 | 关掉后商品左上角不再显示 1、2、3 数字 |
| PC 端启用左右滑动 | 关 | **关**：电脑上多张商品自动换行；**开**：电脑上变成一行横滑，两侧会出现左右箭头 |
| Tab 导航滚动置顶 | 开 | **开**：用户向下滚动时，Tab 行会吸附在页面顶部（盖在 header 之上），方便随时切换分类；**关**：Tab 跟随页面正常滚走 |
| 置顶距离顶部偏移 | 0 px | 启用「滚动置顶」时，Tab 离屏幕顶部多少像素。一般用 0 让它自动贴 header 底部；若你的 header 是透明覆盖在内容上、Tab 被挡住，调到 50～100 px |

## 每个 Tab（排行榜分类）里填什么

每加一个 **块（排行榜分类）** 就多出一个 Tab，最多 10 个。

| 名称 | 怎么填 |
|------|--------|
| 分类名称 | 显示在 Tab 上的文字（不一定等于合集名），例如「パンプス」 |
| 选择分类 | 选一个已经建好的**商品合集**。模块会按合集里的商品顺序作为排行 |
| 产品显示数量 | 1～30；这个分类最多展示几个商品 |
| 查看更多按钮文字 | 该 Tab 下面那个按钮的文字（不填则不显示按钮） |
| 查看更多按钮链接 | 一般填这个合集的页面，例如 `/collections/pumps` |

> 排第几名 = 在合集里排第几个。运营调换顺序：进合集，拖动商品改顺序即可，不用回到这个模块改设置。

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------|
| Tab 切换没反应 / 一直显示第一个 | 多半是页面只有一个 Tab（块），加第二个分类后才看得出切换效果 |
| 排名顺序不对 | 进对应**合集**调整商品排序，不要在这个模块里找 |
| Tab 滚动置顶后挡到内容 | 把「置顶距离顶部偏移」调大几十像素，或关掉「Tab 导航滚动置顶」 |
| 电脑上想看到横滑而不是换行 | 打开「PC 端启用左右滑动」 |
| 想去掉左上角 1、2、3 徽章 | 关掉「显示排行徽章」 |

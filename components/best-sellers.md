# 热销商品

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：kenpogen
:::

**适合做什么：** 顶部 Tab 切换不同商品分组，下方横滑展示带营销标签的商品卡片（MOST LOVED、角标、底部文案、购买按钮等）。支持「选合集自动拉商品」或「手动逐个选商品」两种数据来源。

> 配合用法：若用合集模式，先在后台建好商品合集；卡片上的角标、按钮文案可在每个 Tab 里统一配置。

![热销商品前台效果](/screenshots/best-sellers.png)

## 整段（分区）设置

| 名称 | 怎么填 |
|------|--------|
| 配色方案 | 选择预设配色 |
| 布局 | 主题自带的弹性布局控件 |
| 间距 | 分区上下留白 |
| 移动端布局 | **列布局**：手机端网格展示；**轮播布局**：手机端横滑，每屏约 2.25 张卡片 |
| 箭头按钮背景色 | 商品超过 5 个时出现左右箭头，此处设箭头底色 |

### 标签页样式

| 名称 | 怎么填 |
|------|--------|
| 标签文字颜色 | 未选中 Tab 文字色 |
| 选中标签文字颜色 | 当前 Tab 文字色 |
| 选中标签背景色 | 当前 Tab 背景色 |
| 标签文字大小（桌面端） | 12～32 px，默认 20 |
| 标签文字大小（移动端） | 12～24 px，默认 16 |

## 可添加的内容块

分区最多包含：**标题 ×1**、**副标题 ×1**、**标签页 ×8**。

### 标题 / 副标题

| 名称 | 怎么填 |
|------|--------|
| 标题文字 | 大标题，如「热销商品」 |
| 标题级别 | H1～H6 / P |
| 排版样式 | 主题字号预设 |
| 对齐（桌面 / 移动） | 左 / 中 / 右 |
| 副标题 | 标题下方小字（副标题块） |

### 每一个「标签页」里填什么

每个 Tab 是一组商品。数据来源二选一：

| 方式 | 怎么配 |
|------|--------|
| **合集模式** | 填写「商品分类」，并设「商品数量限制」（1～30，默认 10）；Tab 内不必再加商品块 |
| **手动模式** | 「商品分类」留空，在 Tab 内逐个添加「商品」块并指定商品 |

| 名称 | 怎么填 |
|------|--------|
| 标题 | Tab 上显示的文字 |
| 自动宽度（仅桌面端） | **开**：Tab 宽度随文字；**关**：均分 |
| 商品分类 | 选一个合集；有值时走合集模式 |
| 商品数量限制 | 合集模式下最多展示几件，默认 10 |

#### 分类 / 手动模式共用的卡片样式（在 Tab 层配置）

合集模式下，该 Tab 下所有商品卡共用以下设置；手动模式下每个「商品」块也可单独覆盖。

| 名称 | 怎么填 |
|------|--------|
| 最受欢迎标识 | **开**：显示顶部 MOST LOVED 条 |
| 最受欢迎标识 - 背景色 | 顶部条背景，默认浅蓝 |
| 商品顶部标记文本 | 富文本，默认 `MOST LOVED` |
| 显示商品左侧标记 | **开**：图片左上角显示角标图 |
| 商品左侧标记 | 上传角标图，建议 112×112 |
| 商品右侧标记 - 文本 | 图片右上角文案（富文本） |
| 商品右侧标记 - 背景色 | 右上角底色 |
| 卡片底部标记 - 图标 | 卡片底部小图标，宽约 36px |
| 卡片底部标记 - 文本 | 底部说明文案（富文本） |
| 卡片底部标记 - 背景色 | 底部条背景色 |
| 按钮文本 | 卡片按钮文字，默认 `START BUILDING` |
| 图片比例 | 原始 / 1:1 / 2:3 / 3:4 等 |

### 每一个「商品」块里填什么（仅手动模式）

| 名称 | 怎么填 |
|------|--------|
| 商品 | 选择站点上的商品 |
| 图片比例 | 同上 |
| 最受欢迎标识 / 角标 / 按钮等 | 与 Tab 层字段相同，可单卡覆盖 |

## 与「产品排行榜」的区别

| | 热销商品 | 产品排行榜 |
|---|----------|------------|
| 商品来源 | 每个 Tab 可选合集或手动商品 | 每个 Tab 绑定一个合集 |
| 卡片样式 | 营销向（MOST LOVED、多角标、自定义按钮） | 排名徽章 + Tab 置顶 |
| 典型场景 | 首页 / 活动页种草 | 分类销量榜 |

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------------|
| Tab 有合集但商品不显示 | 合集为空或未发布；检查「商品数量限制」 |
| 手动加了商品块却不生效 | Tab 里已选「商品分类」，合集模式会忽略手动块——清空分类改手动 |
| 没有左右箭头 | 商品 ≤5 个时不显示箭头，属正常 |
| 手机端只能横滑、看不到网格 | 「移动端布局」选的是「轮播布局」；改「列布局」可网格展示 |
| 某张卡没有 MOST LOVED | 关闭「最受欢迎标识」或该商品块单独关掉了 |

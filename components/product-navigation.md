# 产品导航

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：kenpogen
:::

**适合做什么：** 在商品详情页顶部或底部固定一排**锚点按钮**，顾客点击后平滑滚动到页面内对应区域（如「产品详情」「尺码」「评价」等）。

![产品导航前台效果](/screenshots/product-navigation.png)

## 整段（分区）设置

| 名称 | 怎么填 |
|------|--------|
| 文字颜色 | 导航按钮文字颜色，默认黑色 |
| 背景色 | 导航条背景色，默认白色 |
| 显示在顶部 | **开**：导航条在页面顶部；**关**：在页面底部 |

## 每一个「导航项」里填什么

最多 4 个导航项。

| 名称 | 怎么填 |
|------|--------|
| 标题 | 按钮上显示的文字，例如「产品详情」 |
| 锚点选择器 | 目标区域的 CSS 选择器，例如 `#product-details` 或 `.my-section` |
| 顶部偏移 | 0～300 px，默认 150；滚动后距离顶部的额外留白（避开固定顶栏） |
| 返回顶部 | **开**：点击后回到页面最顶部；**关**：按锚点选择器滚动 |

## 配置示例

典型配置：第一个导航项标题「产品详情」，锚点 `#product-details`，偏移 150。

> 目标元素必须在当前商品页 HTML 中存在，且 `id` 或 `class` 与选择器一致，否则点击无反应。

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------------|
| 点击没滚动 | 锚点选择器写错，或目标分区未加对应 id/class |
| 滚到位但被顶栏挡住 | 增大「顶部偏移」数值 |
| 与「产品详情导航」区别 | 本模块按 **页面锚点** 滚动；「产品详情导航」是 **Tab 切换** 多块内容（见该组件说明） |

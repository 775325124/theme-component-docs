# 组件总览

下表统筹**所有主题/店铺**里已提供说明的自定义组件。新增组件时：**加一行 + 新建一篇详细页**，见 [登记规范](/guide/registry)。

::: tip 关于「适用版本」
我们的主题分两套技术架构：**Slate 3.x（Handlebars，文件夹型）** 和 **Slate 2.x（Liquid，扁平）**。
后台运营层面操作几乎一致；技术细节与差异详见 [Slate 2.x vs 3.x 主题差异](/guide/version-difference)。
:::

| 后台里大概叫什么 | 一句话用途 | 适用版本 | 适用主题 / 仓库 | 详细说明 |
|------------------|------------|---------|-----------------|----------|
| **人气视频** | 达人视频墙：封面、短视频、KOL、进商品 | 3.x | daramiyo、kenpogen | [人气视频](/components/kol-recommend) |
| **红人模块** | 多列图文卡片 | 3.x | 同上 | [红人模块（图文）](/components/text-columns-renman) |
| **红人模块(视频)** | 横滑轮播 + 图/视频 | 3.x | 同上 | [红人模块（视频轮播）](/components/text-columns-renman2) |
| **产品排行榜** | 顶部 Tab + 各类合集商品 + 排名徽章；支持滚动置顶 Tab | 3.x | kenpogen | [产品排行榜](/components/product-ranking) |
| **Tab Switcher** | 顶部 Tab + 大图 + 3 商品卡（或纯图）轮播 | 3.x | kenpogen | [Tab 切换图文](/components/tab-switcher) |
| **轮播(自定义数量)** | 横滑图片墙，每屏数量可填小数（如 2.5） | 3.x | kenpogen | [图片轮播 Plus](/components/image-swiper-more) |

> **Slate 2.x 主题（Giipet）目前没有专属自定义组件**，运营如需复用上面 3.x 主题里的某个组件，请联系技术评估是否能反向移植到 Giipet。

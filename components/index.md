# 组件总览

Shopline 自定义分区一览。点「使用说明」查看后台怎么加、每项怎么填。

| 组件 | 介绍 | 使用 |
|------|------|------|
| **人气视频** | 达人视频墙：封面、短视频、KOL 信息，点击进商品 | [使用说明](/components/kol-recommend) |
| **红人模块** | 多列图文卡片：大图 + 标题 + 描述 + 按钮 | [使用说明](/components/text-columns-renman) |
| **红人模块(视频)** | 横滑轮播，卡片可放图或站内/外链视频 | [使用说明](/components/text-columns-renman2) |
| **产品排行榜** | 顶部 Tab + 各类合集商品 + 排名徽章；支持滚动置顶 Tab | [使用说明](/components/product-ranking) |
| **Hot tags** | 热门标签按钮组，可配标题与悬停色 | [使用说明](/components/hot-tags) |
| **通知消息** | 公告列表：绑定自定义页面 + 发布日期 | [使用说明](/components/notice) |
| **热销商品** | Tab + 横滑商品卡，支持合集或手动选品，营销角标 | [使用说明](/components/best-sellers) |
| **Tab Switcher** | 顶部 Tab + 大图 + 3 商品卡（或纯图）轮播 | [使用说明](/components/tab-switcher) |
| **轮播(自定义数量)** | 横滑图片墙，每屏数量可填小数（如 2.5） | [使用说明](/components/image-swiper-more) |
| **图文锚点** | 带标题的图片入口，点击自动滚动到指定区域 | [使用说明](/components/image-text-anchor) |
| **产品描述** | 展示商品后台「描述」正文，可配合详情 Tab 导航 | [使用说明](/components/product-dec) |
| **产品详情** | 图片 / 参数 / 尺码表 / 富文本组合，多块读元字段 | [使用说明](/components/product-detail) |
| **产品详情导航** | 商品页 Tab 切换导航，移动端可吸顶 | [使用说明](/components/product-detail-nav) |
| **产品导航** | 页内锚点按钮，顶部或底部固定 | [使用说明](/components/product-navigation) |
| **产品摘要** | 商品元字段短摘要，支持换行 | [使用说明](/components/product-subtitle) |
| **移动端悬浮购买条** | 商品详情页底部固定加购 / 结账（手机端） | [使用说明](/components/sticky-purchase) |
| **人员穿搭展示** | 员工/KOL 穿搭卡片，支持网格和轮播两种布局 | [使用说明](/components/staff-style-coordination) |
| **评论（Review）** | 星级评论卡片横向轮播，可关联商品加购 | [使用说明](/components/review) |

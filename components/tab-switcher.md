# Tab 切换图文（顶部 Tab + 大图 + 3 商品卡）

**适合做什么：** 顶部一排 Tab（如「新品」「热卖」「促销」），点不同 Tab 切到不同的「大图 + 介绍文字 + 3 个商品」组合，常用做首页主推位、活动专区。模块自带左右切换箭头和分页指示点，也支持自动轮播。

> 模块里每一个**块**就是一个 Tab。块分两种：
> - **Tab Block**：左边大背景图 + 右边 3 个商品卡（最常用）
> - **Image Block**：只有一张大背景图（无商品卡，纯活动入口）

## 整段（分区）设置

### 基础
| 名称 | 怎么填 |
|------|--------|
| 标题 | 整段最上方的大标题（可不填） |
| 背景图片 | 整段的背景图（铺在所有 Tab 之下，多用于装饰，可不填） |

### 字体大小
| 名称 | 说明 |
|------|------|
| 组件标题字体大小(PC) / (M端) | 电脑端、手机端的大标题字号 |
| Tab 标题字体大小(PC) / (M端) | Tab 按钮上的文字字号 |

### 自动轮播
| 名称 | 默认 | 说明 |
|------|------|------|
| 启用自动轮播 | 关 | 开了之后自动切换到下一个 Tab |
| 切换间隔(秒) | 5 | 多少秒切一次 |
| 显示分页指示器 | 开 | 下面的小圆点 / 长条进度 |
| 显示左右箭头 | 开 | 电脑两侧的左右切换箭头 |

### 颜色设置（按后台分组对照）

| 分组 | 调什么 |
|------|------|
| **颜色设置** | 整段背景色、组件标题颜色、Tab 文字（普通/激活）、Tab 背景（普通/激活）、Tab 区内容颜色、跳转链接颜色 |
| **商品卡片颜色** | 卡片背景、加购图标颜色、价格按钮背景、价格按钮文字颜色 |
| **箭头颜色** | 左右箭头的背景与图标颜色 |
| **分页指示器颜色** | 小圆点：未选中颜色、选中颜色 |
| **分区填充** | 主题自带的内部留白控件 |

> 颜色项很多看起来眼花，实际只调你想换的两三个，其余留默认即可。

## 每一个 Tab Block（带 3 商品的 Tab）

| 名称 | 怎么填 |
|------|--------|
| Tab 标题 | Tab 按钮上的文字，例如「新品」「热卖」 |
| **顶部文字区域 — 内容描述** | 进入这个 Tab 后显示的一段富文本介绍 |
| 跳转链接文字 | 介绍下面的「了解更多」类按钮文字（默认「今すぐチェック」） |
| 跳转链接 | 上面这个按钮的去向 |
| **背景图片设置 — 背景图片** | 这个 Tab 左侧的大图 |
| 背景图片跳转链接 | 整张大图可点击，跳到哪 |
| **商品 1 / 2 / 3** | 各选一个站点上的商品（必填，最多 3 个；每个 Tab 都是固定 3 商品位） |
| 商品 X 自定义图片 | 想用别的图替代商品主图时填（不填就用商品自带主图） |
| 显示价格 | 默认开。关掉就不显示价格行 |
| 图片比例 | 原始 / 1:1 / 4:3 / 3:2 / 16:9 / 21:9 |

## 每一个 Image Block（纯图片 Tab）

只有大图、没有 3 商品卡，适合纯活动入口。

| 名称 | 怎么填 |
|------|--------|
| Tab 标题 | Tab 按钮上的文字 |
| 内容描述 / 跳转链接文字 / 跳转链接 | 同上（文字+按钮） |
| 背景图片 / 背景图片跳转链接 | 大图与点击跳转 |
| 图片比例 | 同上 |

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------|
| Tab 切换没用 | 起码加 2 个块才能切换 |
| 商品卡看不到 | 检查每个商品位是否选了商品；或者你用的是 **Image Block**（本来就没有商品卡） |
| 自动轮播不切 | 检查「启用自动轮播」是否开、间隔是不是太长 |
| 箭头/小圆点位置怪、看不清 | 用「箭头颜色」「分页指示器颜色」改成对比明显的颜色 |

# 移动端悬浮购买条

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：kenpogen · **商品详情页 block**（非独立分区）
:::

**适合做什么：** 在手机端商品详情页底部固定显示「加入购物车 + 立即购买」，滚动时始终可见，不依赖主题原生购买按钮区块。

> 配合用法：在 **商品详情** 模板的商品信息区域添加 block「移动端悬浮购买条」。与 `product/_detail-buy-button-group` 可同时存在，按设计决定保留哪一套。

## 在哪里添加？

1. 进入 **在线商店 → 主题 → 自定义**
2. 打开 **商品详情** 模板
3. 在商品主信息 / 商品信息分组里 **添加 block** → 选择 **移动端悬浮购买条**

## block 设置

| 名称 | 怎么填 |
|------|--------|
| 背景色 | 悬浮条底色，默认白色 |
| 文字颜色 | 按钮与文字颜色，默认黑色 |

## 前台行为

- 仅 **移动端** 以底部悬浮条形式展示（样式由 `component-sticky-purchase.css` 控制）
- 含「加入购物车」与主题内置「立即购买 / Shop Pay」按钮
- 售罄时按钮自动禁用并显示售罄文案
- 规格切换时随当前选中变体更新（依赖商品表单联动）

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------------|
| 看不到悬浮条 | block 未加到商品详情模板；或在桌面端预览（该条主要面向手机） |
| 和页面底部购买按钮重复 | 可隐藏原生 `购买按钮组` block，只保留悬浮条 |
| 点击加购无反应 | 检查商品是否可售、规格是否选全；与主题表单冲突时需技术排查 |

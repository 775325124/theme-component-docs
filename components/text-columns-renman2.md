# 红人模块（视频轮播）

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：daramiyo · kenpogen
:::

后台名称可能是 **红人模块(视频)**。和手机淘宝类似的**横滑卡片**：每张可放图，或放**店铺上传的视频 / YouTube、Vimeo 链接**。

![后台截图占位](/screenshots/text-columns-renman2.png)

## 整段（分区）设置

### 标题 / 副标题 / 卡片

- **标题：** 大标题、电脑/手机标题字号、标题粗细。
- **副标题：** 副标题文字、字号、粗细。
- **卡片：** 图片宽度、图片比例、文字对齐（和 [红人模块（图文）](/components/text-columns-renman) 类似）。

### 轮播设置（最重要）

| 名称 | 白话说明 |
|------|----------|
| PC端每屏显示卡片数 | 数字**越大**，电脑一行里**挤进去的卡片越多**（单张越小）；数字**越小**，每张越大。按预览效果拖一拖即可。 |
| 移动端每屏显示卡片数 | 同上，管手机一行露几张。 |
| PC端卡片间距 / 移动端卡片间距 | 卡片之间的空隙大小。 |
| 显示左右切换按钮 | 电脑两侧箭头；手机端一般会隐藏箭头，主要靠手指滑。 |
| 显示分页指示点 | 下面小圆点，点哪张到哪张。 |
| 循环滚动 | 滑到最后再滑会回到开头（卡片要够多时才明显）。 |
| 自动播放 / 自动播放间隔 | 是否自动轮播、隔几秒换下一张。 |

### 底部按钮 / 分区填充

- **底部按钮：** 整段下面一个总按钮的文字和链接。
- **分区填充：** 与上下的留白。

## 每一张卡片里填什么

可以只上图，也可以主要放视频：

| 名称 | 怎么填 |
|------|--------|
| 图片 | 若填了图，会优先显示成可点击的图（点跳转看「跳转链接」）。 |
| 封面图 | 放视频时，视频没出来前显示的画面。 |
| 视频文件 | 在后台上传的短视频。 |
| 外部视频链接 | 粘贴 YouTube、Vimeo 等页面链接。 |
| 自动播放 | 打开后一般会**静音**自动播（浏览器要求），具体以预览为准。 |
| 标题、标题字体大小、图标、描述、按钮文字、跳转链接 | 和视频/图下面的文案区，和图文红人模块类似。 |

## 小提示

- 想「以视频为主」：重点填封面 + 视频文件或外链；图片可不填或作备用。
- 自动轮播、循环若感觉没生效，多半是卡片张数太少，多添加几张再试。

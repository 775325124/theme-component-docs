# 图片轮播 Plus（自定义每屏数量）

::: info 适用范围
**Slate 3.x（Handlebars）** · 主题：kenpogen
:::

**适合做什么：** 横滑图片墙，能精确控制「电脑上一屏露几张」「移动端要不要单独排版」。比主题自带的轮播更灵活：
- 数量可以填小数（例如 `2.5`），表示一屏露 2 整张 + 半张，**暗示用户右边还有内容**。
- 每张图可以分别配 PC 图和移动端图，还可以叠一个「按钮图」点击跳转。

![后台截图占位](/screenshots/image-swiper-more.png)

## 整段（分区）设置

### 标题
| 名称 | 怎么填 |
|------|--------|
| Title | 这段最上方的大标题（可不填） |
| Sub Title | 副标题 |

### 数量与展示
| 名称 | 怎么填 |
|------|------|
| **展示数量** | 数字越大每张越小。**关键**：可填小数。例如 `2.5` 表示一屏展示 2 张完整图 + 第 3 张露一半（吊用户向右滑）。整数 1、2、3、4… 就是一屏整数张 |
| PC 展示 | 关掉则整个模块在电脑端隐藏（一般保持开） |
| 全屏宽度 | 开：图片铺满浏览器宽度；关：跟主题正文一样有左右留白 |
| 移动端是否单独展示 | 开：手机端用「移动端图片」（每张块里单独配的图）；关：手机端复用 PC 图 |
| 移动端显示缩略图 | 开了之后手机端下方会显示一排小缩略图 |

### 自动播放
| 名称 | 怎么填 |
|------|------|
| 自动播放 | 开了之后自动横滑 |
| 切换时间 | 多少毫秒换一张（注意单位是毫秒，1 秒 = 1000） |

### 分页指示器
| 名称 | 怎么填 |
|------|------|
| 分页样式 | 长条进度 / 圆点 |
| PC 端分页定位到图片内 | 开：分页器叠在图片底部内；关：分页器在图片下方 |
| 移动端分页定位到图片内 | 同上，分别控移动端 |

### 图片比例（CLS 优化）

预先告诉浏览器每张图的长宽比，避免图加载完后内容跳动（搜索引擎友好）。

- PC 端图片比例：`1:1`、`4:5`、`3:4`、`2:3`、`4:3`、`16:9`，或 `自适应`
- 移动端图片比例：同上

> 实际图片本身的比例最好和这里选的一致，否则会有空白或裁切。**「自适应」会有 CLS（页面跳动），不推荐**，除非你拿不准比例。

### 其它
| 名称 | 怎么填 |
|------|------|
| 文字对齐 | 卡内文字的对齐方式（左 / 中 / 右） |
| 分区填充 | 主题自带的内部留白控件 |

## 每一张「图片滑块」块里填什么

| 名称 | 怎么填 |
|------|--------|
| PC 端图片 | 电脑端显示的图 |
| 移动端图片 | 手机端显示的图（**开了**整段「移动端是否单独展示」时才生效；不填就回退到 PC 图） |
| 图片链接 | 整张图点击跳到哪 |
| 标题 | 图上的文字标题（可不填） |
| **按钮图片** | 叠在图上的一张小图（通常是「立即购买」「了解更多」之类的设计稿按钮，由设计师切好 PNG） |
| 按钮链接 | 按钮图自己的跳转链接（一般和图片链接相同，也可不同） |

## 常见疑问

| 现象 | 原因 / 处理 |
|------|------|
| 一屏只露 1 张但我想露 2.5 张 | 在「展示数量」里填 `2.5` |
| 切换间隔写 5 没反应 / 太快 | 单位是**毫秒**，5 秒应填 `5000` |
| 移动端图被拉变形 | 检查「图片比例」选的比例和你上传的图实际比例是否一致 |
| 手机看到的还是 PC 图 | 打开「移动端是否单独展示」，并在每个块里上传「移动端图片」 |
| 想让用户感觉「右边还有内容」 | 在「展示数量」用小数（如 `2.3`、`2.5`），让最后一张露一截 |

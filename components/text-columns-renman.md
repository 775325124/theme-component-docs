# 红人模块（图文多列）

::: info 适用范围
**Slate 3.x（Handlebars）** · 主题：daramiyo · kenpogen
:::

**适合做什么：** 多张「大图 + 标题 + 可选小图标 + 文字介绍 + 按钮」，电脑上几列排开；手机可以一排多张，或左右滑一张一张看。

![后台截图占位](/screenshots/text-columns-renman.png)

## 整段（分区）设置

| 名称 | 怎么填 |
|------|--------|
| 标题 / 标题大小 / 标题粗细 | 这一段的大标题样式 |
| 副标题 / 副标题字号 / 副标题粗细 | 标题下面一行说明 |
| 图片宽度 | 每张卡里图占多宽：整宽、一半、约三分之一 |
| 图片比例 | 方图、竖图、圆头像等 |
| PC端列数 | 电脑一行排几张（1～6） |
| 移动端列数 | **没开**下面「触摸滑动」时，手机一行排 1 张还是 2 张 |
| 文字对齐 | 卡片里文字和按钮靠左还是居中 |
| 移动端触摸滑动 | **打开**：手机变成左右滑一张，底下有 1/总数；**关闭**：手机按「移动端列数」网格排 |
| 按钮文字 / 按钮链接 | 这一段最底下的一个大按钮（没有可不填） |
| 分区填充 | 这一段与上下内容的间距，用主题自带的间距控件调即可 |

## 每一张「红人卡片」里填什么

| 名称 | 怎么填 |
|------|--------|
| 图片 | 主图 |
| 标题 / 标题字体大小 | 卡片标题 |
| 图标 | 标题旁边小图（可不填） |
| 描述 | 正文，支持简单排版 |
| 按钮文字 / 跳转链接 | 这张卡自己的按钮（没有可不填） |

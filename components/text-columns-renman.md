# 红人模块（图文多列）

::: info 适用范围
**Shopline 3.x（Sline）** · 主题：daramiyo · kenpogen
:::

**适合做什么：** 多张「大图 + 标题 + 可选小图标 + 文字介绍 + 按钮」，电脑上几列排开；手机可以一排多张，或左右滑一张一张看。

![红人模块前台效果](/screenshots/text-columns-renman.png)

## 整段（分区）设置

| 名称 | 怎么填 |
|------|--------|
| 标题 | 这一段的大标题 |
| 标题大小 | 大-标题1 / 中-标题3 / 小-标题5，默认中-标题3 |
| 标题粗细 | 正常 / 加粗 |
| 副标题 | 标题下面一行说明 |
| 副标题大小 | 默认 / 标题1～6 / 正文1～6，默认正文3 |
| 副标题粗细 | 正常 / 加粗 |
| 图片宽度 | 每张卡里图占多宽：整宽、一半、约三分之一 |
| 图片比例 | 自适应 / 1:1 / 3:4 / 圆形 |
| PC端列数 | 电脑一行排几张（1～6） |
| 移动端列数 | **没开**「触摸滑动」时，手机一行排 1 张还是 2 张 |
| 文字对齐 | 卡片里文字和按钮靠左还是居中 |
| 移动端触摸滑动 | **开**：手机横滑一张 + 页码；**关**：按「移动端列数」网格排 |
| 移动端每屏显示卡片数 | 开启触摸滑动时，手机一屏露几张（10～100，数值÷10，如 20=2 张） |
| 按钮文字 / 按钮链接 | 整段最底下的大按钮（可不填） |
| PC 端上下间距 / PC 端左右间距 | 电脑端卡片行距、列距（滑条） |
| 移动端上下间距 / 移动端左右间距 | 手机端卡片行距、列距 |
| 分区填充 | 与上下内容的留白 |

## 每一张「红人卡片」里填什么

| 名称 | 怎么填 |
|------|--------|
| 图片 | 主图 |
| 标题 / 标题字体大小 | 卡片标题 |
| 图标 | 标题旁边小图（可不填） |
| 描述 | 正文，支持简单排版 |
| 按钮文字 / 跳转链接 | 这张卡自己的按钮（没有可不填） |
